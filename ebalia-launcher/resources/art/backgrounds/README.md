# Minecraft backgrounds

Official wallpaper artwork downloaded from [Minecraft wallpapers](https://www.minecraft.net/en-us/collectibles) for this local launcher customization. Images are embedded so the carousel and archive artwork also work offline.

Artwork: Mojang Studios / Microsoft. These images are not covered by the launcher's code license. `sources.json` records each original download and archive filename.

The Home carousel uses Trails & Tales, Chase the Skies, Spring to Life and Tricky Trials. Every one of the 15 Lost Versions entries has its own distinct wallpaper, assigned by version ID in `Ui::lostArtFor`. The archive artwork is illustrative, not a screenshot of the selected historical version.
