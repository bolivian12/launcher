Requisitos y otras distribuciones de Linux

No existe un binario probado en todas las distribuciones. El paquete Linux de esta versión se compila en Ubuntu 24.04 y necesita bibliotecas compatibles. El código fuente permite compilar para otras distribuciones con CMake, C++20, Qt 6 y libarchive. Consultá el README antes de instalar.

Los paquetes se muestran cuando terminan las compilaciones y se adjuntan a la versión. Windows y macOS pueden distribuirse sin firma digital. No se incluyen cuentas de Minecraft.
